# Listas de Python — IFCE

Repositório destinado às **listas e atividades de Python** desenvolvidas durante o Curso Técnico em Informática do **IFCE — Campus Maranguape**.

As atividades deste repositório foram propostas pelos professores **Thomaz** e **Jessyca**, como parte dos estudos de programação em Python.

## 📚 Conteúdo

Aqui serão armazenadas as listas de exercícios e atividades de Python realizadas durante o curso, incluindo conteúdos como:

* `if`, `elif` e `else`
* `while`
* Estruturas de repetição
* Entrada e saída de dados
* Operações e cálculos
* Outros conteúdos de programação em Python
